# Инструкции для ИИ-агента (Codex, Claude, Cursor и т.п.)

Этот файл — для нейросети, которая будет дорабатывать проект. Пользователям сайта он не показывается.

## Главное правило

Исходный проект (stikech/ku-portal) не менять без необходимости. Не трогать: главную, расписание, оценки, рейтинг, AI-помощника, вход и регистрацию, профиль. Дизайн задаётся CSS-переменными в `public/style.css` (`:root`) — новые экраны строить на них, свои цвета не вводить.

## Раздел «Экзамен» = вход в «Онлайн-экзамен»

Электронная очередь на спикинг из портала **удалена полностью** (экраны, API `/api/exam/*`, `/api/teacher/sessions*`, `/api/teacher/queue*`, SSE `/api/events`, демо-комнаты). Не восстанавливать её. Экзамены — тесты, writing, speaking-очередь, ведомость — живут в сервисе «Онлайн-экзамен».

- `public/app.js`, функция `viewExam()` — экран раздела «Экзамен» для студента и преподавателя: описание сервиса, проверка доступности, кнопка «Перейти к онлайн-экзамену» (с анимацией перехода) и «Открыть в новой вкладке». Маршруты `#/exam` и `#/t/queue` (а также старые `#/exam/...`, `#/t/room/...`) ведут сюда.
- `exam-sync/` — сервис «Онлайн-экзамен» из github.com/StephCurrysvg/exam-sync, встроенный в этот же сервер:
  - `exam-sync/handler.js` — сервер синхронизации, смонтирован в `server.js` под префиксом `/exam-sync` (`GET /exam-sync/`, `GET /exam-sync/api/state`, `GET /exam-sync/api/events` — SSE, `POST /exam-sync/api/sync`);
  - `exam-sync/index.html` — интерфейс. Пути к API в нём относительные (`api/sync`), поэтому страница должна открываться по адресу с завершающим `/` (сервер сам перенаправляет `/exam-sync` → `/exam-sync/`);
  - данные — `data/exam-sync.json` (в `.gitignore`), при первом запуске — демо из `exam-sync/seed.json`.
- Переход портал → экзамены: `/exam-sync/?from=ku-portal&back=<адрес портала>/#/exam`. Сайт экзаменов запоминает `back` на сессию вкладки, убирает параметры из адреса и показывает кнопку «KU Portal». `back` принимается только http(s) и только с того же хоста, хостов портала на Render, localhost или локальной сети (`KU_HOSTS`, `kuHostOk` в `exam-sync/index.html`).
- Вход в онлайн-экзамен отдельный от портала (свои аккаунты exam-sync).

## Проверка после изменений

1. `node --check server.js`, `node --check public/app.js`, `node --check exam-sync/handler.js` проходят, `node server.js` запускается без ошибок.
2. Вход под `teacher@demo.kz` / `1234` и `student@demo.kz` / `1234`: «Экзамен» сразу показывает вход в онлайн-экзамен, кнопка открывает `/exam-sync/`, там есть кнопка «KU Portal», она возвращает в портал.
3. Главная, расписание, оценки, рейтинг, AI-помощник, профиль работают как раньше.
4. Деплой — Render (`render.yaml`, `node server.js`, без зависимостей). Если автодеплой не сработал: Render → Manual Deploy → Deploy latest commit.
